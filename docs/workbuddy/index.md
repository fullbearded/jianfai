# WorkBuddy 从入门到放弃

> 只会用 DeepSeek 问一句答一句？WorkBuddy 换了个逻辑：你不是在问它，是把一件事交给它，做完给你验收。从入门到放弃，最后一课是知道哪些事不该用 AI。

本页回答两个问题：**看清这套教程全景**，**你决定从哪一篇读起**。

## 教程为什么这样设计

大多数人学工具的顺序是反的：先装，再找用途，最后发现**用不上**。这套教程把顺序正过来，按一个人真实的成长曲线编排：**先判断值不值得做，再能用，再常用，再沉淀成系统，最后知道什么时候不用**。

工具会变，方法不变。

> 为什么最后一章是「放弃」？
> 因为市面上的教程都在教你「多用」，没人教你「**什么时候不用**」。把 AI 用在对的地方，比用得多更重要。

## 怎么用这套教程

- **顺序读**：跟着五个阶段走，适合从零开始的人。
- **按需跳读**：带着具体问题，先查[附录 B 场景速查表](/workbuddy/tutorial/附录/B-场景速查表)，按场景反查对应篇章。
- **对着验收读**：每篇都有「按标准验收」，跑不通就不算学会。
- **读完就沉淀**：每篇末尾的「沉淀可复用资产」才是重点，工具会变，资产留下。

三条最省时间的路径：

| 你现在的状态 | 建议路径 |
| --- | --- |
| 零基础，想快速上手 | [0.2 三个自检问题](/workbuddy/tutorial/00-序章/02-三个自检问题) → [第一章 入门](/workbuddy/tutorial/01-入门/) |
| 已经在用，想用得更稳 | 直接进 [第二章 进阶](/workbuddy/tutorial/02-进阶/) |
| 想把重复工作一次性做成模板 | [第三章 精通](/workbuddy/tutorial/03-精通/) + [第四章 放弃](/workbuddy/tutorial/04-放弃/) |
