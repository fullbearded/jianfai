# 第一章 · 入门：先把 WorkBuddy 用起来

> 本系列：《WorkBuddy 从入门到放弃》 · 本章 6 篇 · 约 1 小时

入门的目标只有一个：跑通第一个真实任务，并且能验收。不是把功能都看一遍，而是让 WorkBuddy 在你的电脑上，实实在在帮你干成一件事。走完这一章，你会有一份能重复的工作目录和一个跑得通的任务。

## 本章目标

- 装上、登录、更新 WorkBuddy
- 看懂主界面、任务与工作区这三样
- 跑通第一个真实任务，并装上第一个用得上的 Skill
