# 1.5 给 WorkBuddy 装上第一个 Skill

> 本系列：《WorkBuddy 从入门到放弃》 · 第一章 入门 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你能说清 Skill 是什么，并亲手加载一个解决你真实问题的 Skill。

## 本篇要点

- Skill 是把一套做法固化成可加载、可复用的能力
- 挑 Skill 的前提是你已经有一个想解决的真实任务
- 加载后先小范围试用，再决定要不要长期用
- 用得顺手，就到第三章自己动手做 Skill

## 内容大纲（待撰写）

- Skill 是什么：和「提示词」的区别
- 去哪里找：官方与社区的 Skill 来源
- 怎么挑：对照你自己的高频任务选，不贪多
- 加载与试跑：一次只装一个，跑通再装下一个

## 按标准验收

- [ ] 你能解释 Skill 和普通提示词的区别
- [ ] 你成功加载并跑通了一个 Skill

## 沉淀可复用资产

做完这篇，你应该沉淀出：一个正在用的 Skill，以及它替你省下的那件事。
