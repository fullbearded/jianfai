# 1.6 入门验收清单与报错自救

> 本系列：《WorkBuddy 从入门到放弃》 · 第一章 入门 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你能判断自己算不算入门，并在遇到报错时按顺序自己排查。

## 本篇要点

- 入门不看功能会几个，只看能不能稳定跑通一个任务
- 验收清单按「安装、任务、Skill」三块逐条勾
- 报错先分层：环境问题、描述问题、还是能力边界问题
- 大多数卡住不是工具坏了，而是任务没说清

## 内容大纲（待撰写）

- 入门验收清单：安装、第一个任务、第一个 Skill
- 报错分层排查：安装失败、登录失败、任务跑偏、结果不对
- 自救顺序：先看日志、再简化任务、最后求助
- 什么时候该放弃：连到第四章

## 按标准验收

- [ ] 验收清单全部勾选
- [ ] 你能独立排查至少两类常见报错

## 沉淀可复用资产

做完这篇，你应该沉淀出：一份自己的入门验收清单。
