# 1.3 WorkBuddy 主界面、任务与工作区

> 本系列：《WorkBuddy 从入门到放弃》 · 第一章 入门 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你能指出界面上每一块是干什么的，以及一个任务从哪来、去哪验收。

## 本篇要点

- 主界面：发起任务、查看过程、拿到结果的地方
- 任务：一次要完成的事，有输入、过程和产出
- 工作区：任务运行所处的目录环境，文件进出的边界
- 三者的关系：一个工作区可以承接很多任务

## 内容大纲（待撰写）

- 界面分区导览：输入区、过程区、结果区
- 任务的生命周期：发起、执行、检查、交付
- 工作区怎么建：命名、隔离、备份
- 常见误区：把工作区和桌面混在一起

## 按标准验收

- [ ] 你能说出一个任务从发起到验收的完整路径
- [ ] 你能为不同项目建出互不干扰的工作区

## 沉淀可复用资产

做完这篇，你应该沉淀出：一套你自己的工作区命名规则。
