# 2.6 场景 Case：会议、远程、生活、GEO

> 本系列：《WorkBuddy 从入门到放弃》 · 第二章 进阶 · 预计阅读 12 分钟

## 这一篇解决什么问题

看完这篇，你能从几个真实 Case 里找到和你最像的那一个，照着落地。

## 本篇要点

- 会议不是终点：纪要、待办、协作交付一条龙
- 远程控制：不在电脑前也能推进任务
- 生活助手：把琐碎交出去
- GEO 诊断：给自己或客户做一次可见度体检

## 内容大纲（待撰写）

- 每个 Case 的通用结构：场景、工具、过程、效果
- 会议闭环 Case 拆解
- 远程控制与移动验收
- 生活助手与资讯整合
- GEO 品牌诊断：评分框架与优化建议

## 按标准验收

- [ ] 你选了一个 Case 并完整跑通
- [ ] 你能说出它和你的工作哪里最像

## 沉淀可复用资产

做完这篇，你应该沉淀出：一个属于你自己场景的 Case 草稿。
