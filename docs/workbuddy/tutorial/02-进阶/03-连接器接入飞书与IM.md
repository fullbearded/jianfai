# 2.3 连接器：把 WorkBuddy 接入飞书与 IM

> 本系列：《WorkBuddy 从入门到放弃》 · 第二章 进阶 · 预计阅读 12 分钟

## 这一篇解决什么问题

看完这篇，你能把 WorkBuddy 接进你每天已经在用的工具里。

## 本篇要点

- 连接器解决「AI 和我的工具是两套」的问题
- 飞书实战：从接入到交付，把任务放进办公流程
- IM 与小程序：随时随地发起和验收任务
- 外部 API：把 WorkBuddy 接进你自己的系统

## 内容大纲（待撰写）

- 连接器是什么，能连什么
- 飞书接入：授权、配置、跑通一个真实办公任务
- 小程序与 IM 助理：移动端发起任务
- 外部 API：给自己的系统开一个口子
- 安全边界：哪些数据可以连、哪些不要连

## 按标准验收

- [ ] 你完成了一个连接器的接入
- [ ] 你能在飞书或 IM 里直接发起并验收一个任务

## 沉淀可复用资产

做完这篇，你应该沉淀出：一份连接器的接入与安全配置清单。
