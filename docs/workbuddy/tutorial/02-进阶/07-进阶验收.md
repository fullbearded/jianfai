# 2.7 进阶验收：你能教别人了吗

> 本系列：《WorkBuddy 从入门到放弃》 · 第二章 进阶 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你能判断自己算不算进阶，并知道离精通还差什么。

## 本篇要点

- 进阶的验收标准：你能把一套流程完整讲给别人
- 检查三样：指令模板、专家团、连接器都用起来了吗
- 讲不清的地方，就是你还没真懂的地方
- 下一章开始，从「用工具」转向「造系统」

## 内容大纲（待撰写）

- 进阶验收清单
- 自测方法：写一份给别人看的操作说明
- 常见的「以为会了」：会点按钮，但说不清逻辑
- 通往精通的三个信号

## 按标准验收

- [ ] 你为一套流程写了一份可教给别人的说明
- [ ] 你能不查资料地讲清关键步骤

## 沉淀可复用资产

做完这篇，你应该沉淀出：一份可交接给你的同事的操作说明。
