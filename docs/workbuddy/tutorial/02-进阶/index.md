# 第二章 · 进阶：把它用成一支 AI 团队

> 本系列：《WorkBuddy 从入门到放弃》 · 本章 7 篇 · 约 2 小时

入门是「用一次」，进阶是「一直用」。这一章的目标，是把 WorkBuddy 接进你每天的流程：用可复制的指令减少重复描述，用专家团固定分工，用连接器让工具长在流程里。走完这一章，你不再是每次从零开始对话，而是有一套随时能调用的团队。

## 本章目标

- 建立一套可复制的指令模板，减少重复描述
- 用专家与专家团把角色和分工固定下来
- 用连接器把 WorkBuddy 接进飞书、IM 与日常工具
