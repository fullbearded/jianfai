# 2.5 用 WorkBuddy 管理文件与知识库

> 本系列：《WorkBuddy 从入门到放弃》 · 第二章 进阶 · 预计阅读 12 分钟

## 这一篇解决什么问题

看完这篇，你能让 WorkBuddy 帮你收拾文件和信息，而且下次找得到、用得上。

## 本篇要点

- 桌面文件整理：先分类规则，再让 AI 执行
- 资讯整合：把信息流变成每日通知，而不是收藏夹
- 知识库：收藏不算管理，能再次用起来才算
- 工具组合：WorkBuddy 与 ima、Obsidian 的配合

## 内容大纲（待撰写）

- 文件整理先从定规则开始，AI 只做执行
- 资讯整合：抓取、筛选、定时推送
- 知识库搭建：WorkBuddy 加 ima、Obsidian 加 WorkBuddy 两条路线
- 复用的判据：三个月后还能不能找到并直接用

## 按标准验收

- [ ] 你整理好了一个混乱的目录
- [ ] 你搭起了一个能再次用起来的资料库

## 沉淀可复用资产

做完这篇，你应该沉淀出：一套文件命名与归档规则。
