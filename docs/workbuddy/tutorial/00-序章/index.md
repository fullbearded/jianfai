# 序章 · 先想清楚要不要开始

> 本系列：《WorkBuddy 从入门到放弃》 · 本章 3 篇 · 约 20 分钟

- 用三个问题评估你的场景值不值得自动化
- 看懂 WorkBuddy 能做什么、不能做什么
