# 3.1 打造 Skill：把书和视频蒸馏成可执行能力

> 本系列：《WorkBuddy 从入门到放弃》 · 第三章 精通 · 预计阅读 12 分钟

## 这一篇解决什么问题

看完这篇，你能把一个知识来源变成可执行的 Skill，而不是又一份笔记。

## 本篇要点

- 蒸馏的目标是可执行，不是可收藏
- 从书和视频里提取动作，而不是摘抄金句
- 一个 Skill 只解决一类任务
- 做完要能加载、能跑、能验收

## 内容大纲（待撰写）

- 蒸馏四步：提炼动作、定义输入输出、写成指令、试跑修正
- 案例：把一本书的方法变成一个 Skill
- 案例：把一段视频的流程变成一个 Skill
- 反面例子：把一整本书塞进一个 Skill

## 按标准验收

- [ ] 你把一个知识来源蒸馏成了一个可加载的 Skill
- [ ] 该 Skill 在某类任务上稳定可复现

## 沉淀可复用资产

做完这篇，你应该沉淀出：你的第一个自制 Skill。
