# 3.2 Skill 封装方法论

> 本系列：《WorkBuddy 从入门到放弃》 · 第三章 精通 · 预计阅读 12 分钟

## 这一篇解决什么问题

看完这篇，你能把一条完整工作流拆开，每个环节封一个 Skill。

## 本篇要点

- 先拆环节，再逐个封装，别一口吃成系统
- 每个环节对应一个 Skill：输入清楚、输出可验收
- 以内容生产为例：定位、选题、创作、复盘
- 封装的意义是把「你的经验」变成「可交接的能力」

## 内容大纲（待撰写）

- 为什么按环节封装：易维护、易替换、易复用
- 环节拆解方法：从一次真实工作的流程里切
- 四个示例 Skill：定位、选题、创作、复盘
- Skill 之间的关系：谁喂给谁，怎么串起来

## 按标准验收

- [ ] 你把一条工作流拆成了多个环节
- [ ] 你为其中至少两个环节各封了一个 Skill

## 沉淀可复用资产

做完这篇，你应该沉淀出：一条按环节封装的工作流。
