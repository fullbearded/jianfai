# 3.7 精通验收：你的系统能交接吗

> 本系列：《WorkBuddy 从入门到放弃》 · 第三章 精通 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你能判断自己算不算精通，并知道离「放弃」那一章还有多远。

## 本篇要点

- 精通的验收标准：你的系统能被别人接手
- 检查：Skill 有文档吗，流程有说明吗，失败有兜底吗
- 交接不了，说明系统还挂在你一个人身上
- 走到这里，才有资格谈「什么时候该放弃」

## 内容大纲（待撰写）

- 精通验收清单
- 自测：把你的系统交给同事，他能跑起来吗
- 交接文档该包含哪些内容
- 从精通到放弃：为什么最后一章是教你别用

## 按标准验收

- [ ] 你为一套系统写完了交接文档
- [ ] 同事能照着文档独立跑起来

## 沉淀可复用资产

做完这篇，你应该沉淀出：一份可交接的系统文档。
