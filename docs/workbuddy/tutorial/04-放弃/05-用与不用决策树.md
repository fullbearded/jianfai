# 4.5 用与不用决策树

> 本系列：《WorkBuddy 从入门到放弃》 · 第四章 放弃 · 预计阅读 8 分钟

## 这一篇解决什么问题

看完这篇，你手上任何一件任务，都能顺着决策树找到该用、该半自动、还是该手动。

## 本篇要点

- 决策树把前三篇的自检、成本、反模式收进一张图
- 从「频率」开始问，逐步收敛到具体级别
- 每个分叉都有明确的判断条件
- 树的终点不只有「用」，也有「不用」

## 内容大纲（待撰写）

- 决策树全图与每一步的判断依据
- 三个典型任务走一遍决策树
- 怎么把决策树贴在你自己的工作流里
- 与序章三个自检问题的对应关系

## 按标准验收

- [ ] 你能画出这棵决策树的简化版
- [ ] 你用它为三个任务做过判断

## 沉淀可复用资产

做完这篇，你应该沉淀出：一张随手可查的用与不用决策树。
