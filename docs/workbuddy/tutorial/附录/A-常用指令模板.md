# 附录 A：常用指令模板

> 本系列：《WorkBuddy 从入门到放弃》 · 附录 · 预计阅读 6 分钟

## 这一篇解决什么问题

给你一批可直接复制、改成自己参数的指令模板，省去每次从零描述。

## 本篇要点

- 模板按任务类型归类，复制即用
- 方括号里的是要替换的参数
- 模板要克制，够用就好
- 用完记得回填验收标准

## 内容大纲（待撰写）

- 任务定义模板（背景、要什么、怎么算完成）
- 报告与写作模板
- 数据分析模板
- 内容创作与选题模板
- 每个模板配一段使用说明

## 按标准验收

- [ ] 你复制并成功使用了至少两个模板
- [ ] 你把其中一个改成了自己的常用版本

## 沉淀可复用资产

做完这篇，你应该把模板收进自己的指令库。
