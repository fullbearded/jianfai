## 提交你的场景

有工作场景不知道怎么用 AI 解决？交给我们，做成开源 Case。

**四步流程**：提交场景 → 理解场景 → 评估路径 → 制作开源 Case

提交前建议准备：

1. 真实场景描述
2. 当前做法与耗时
3. 输入资料样例（可脱敏）
4. 期望结果
5. 安全边界（哪些数据不能出本地）
