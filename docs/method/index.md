# 简法工作法

> 工具会变，方法不变。

## 五步总览

<FiveStep :current="0" :labels="['识别任务', '五要素定义', '分阶段执行', '按标准验收', '沉淀模板']" />

### 第 1 步：识别任务

不是所有事都值得 AI 接手。找「高频、耗时、有明确产出」的任务。

### 第 2 步：五要素定义

任务定义工具，一次说清：

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| 任务 | 做什么 | 周报汇总 |
| 输入 | 给 AI 什么 | 各部门周报原文 |
| 标准 | 什么样算好 | 格式模板 + 字段齐全 |
| 边界 | 不能碰什么 | 不改原始数据 |
| 产出 | 交付什么 | 一页周报 |

### 第 3 步：分阶段执行

拆成 AI 擅长的小步：先做素材整理，再做初稿，最后人来做终审。

### 第 4 步：按标准验收

结果对照第 2 步定义的标准。不合格就回到定义层修，而不是手工兜底。

### 第 5 步：沉淀可复用模板

这次的做法变成下次的起点——这就是[简法模板库](/community/)的来源。
